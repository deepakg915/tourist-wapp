# Tourist Planner

A React application to plan your trips, compare hotels, and optimize your itinerary.

## Setup

Since this project was created manually, you need to install dependencies and run it using a Node.js environment.

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

## Features
- City Search
- Tourist Spot Recommendations
- Hotel Comparisons
- Optimized Itinerary Generation
